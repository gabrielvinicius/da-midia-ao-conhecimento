\subsection{Proposta de Solução de Software}
    A proposta consiste no desenvolvimento de uma plataforma web que permita ao usuário fazer o upload de vídeos, os quais serão automaticamente processados para extração de áudio, transcrição textual e geração de resumos usando modelos de linguagem avançados.

    A solução será composta por módulos bem definidos, como autenticação, gerenciamento de vídeos, transcrição, sumarização e notificações, integrados entre si por uma arquitetura limpa e modular. O sistema será capaz de realizar todo o processo de forma assíncrona, garantindo resposta rápida mesmo com vídeos longos.

    A plataforma é importante pois oferece uma alternativa prática e eficiente para o consumo de conteúdo audiovisual, permitindo maior agilidade na busca por informações-chave e otimizando o tempo dos usuários.
