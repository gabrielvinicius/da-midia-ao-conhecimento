\subsection{Projeto de testes}

    O projeto adota uma estratégia de testes baseada em testes unitários e funcionais, utilizando o framework Pytest. Cada componente crítico do sistema (serviços, repositórios, utilitários) possui cobertura de testes automatizados. Além disso, mocks são utilizados para isolar dependências externas durante os testes.

    Foram implementados também testes de integração para validar fluxos completos, como o upload de um vídeo, sua transcrição e geração de resumo. Ferramentas como Coverage.py foram usadas para medir a cobertura de código e identificar áreas que necessitam de novos testes.

    A automação dos testes é realizada com integração contínua (CI), garantindo que todas as alterações passem por verificação antes de serem mescladas ao branch principal.
