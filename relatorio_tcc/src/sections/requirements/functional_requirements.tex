\subsection{Requisitos Funcionais}
    \begin{description}
        \item [RNF1] - Como usuário, desejo me registrar e fazer login para utilizar a plataforma.
        \item [RNF2] - Como usuário, quero fazer upload de vídeos para iniciar o processo de resumo.
        \item [RNF3] - Como usuário, preciso receber notificações quando o vídeo for processado.
        \item [RNF4] - Como usuário, quero visualizar a transcrição completa do vídeo.
        \item [RNF5] - Como usuário, quero visualizar o resumo gerado automaticamente.
        \item [RNF6] - Como usuário, quero listar todos os vídeos já processados.
        \item [RNF7] - Como administrador, quero monitorar o status dos vídeos processados.
    \end{description}
