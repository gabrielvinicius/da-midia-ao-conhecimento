\subsection{Requisitos Não-Funcionais}
    \begin{description}
        \item [RNF1] O sistema deve ser acessível via navegador web.
        \item [RNF2] O sistema deve responder a requisições em até 5 segundos em condições normais de carga.
        \item [RNF3] O sistema deve suportar múltiplos usuários simultâneos.
        \item [RNF4] O sistema deve utilizar criptografia para autenticação e armazenamento de senhas.
        \item [RNF5] O sistema deve ser tolerante a falhas durante o processamento de vídeos.
    \end{description}
