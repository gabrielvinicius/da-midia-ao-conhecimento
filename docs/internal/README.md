# Internal Artifacts

This directory centralizes legacy documents, analysis outputs and helper artifacts that were previously scattered at the repository root.

- `notes/`: temporary instructions, migration notes and misc files (e.g., legacy change logs, cookies, .changeset drafts).
- `analysis/`: auto-generated dependency graphs, SVGs or JSON snapshots used during refactors.

These files are **not** part of the shipping product but are useful for internal context. Keep future ad-hoc artifacts inside these folders instead of polluting the repo root.
